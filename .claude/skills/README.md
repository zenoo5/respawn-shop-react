# Vercel React skills

Installed from the official [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) repository:

- `vercel-react-best-practices` comes from `skills/react-best-practices`.
- `vercel-composition-patterns` comes from `skills/composition-patterns`.

Both directories include their upstream `SKILL.md`, compiled `AGENTS.md`, README, metadata, and complete `rules` directory. Keep these vendored sources unchanged. `sources.json` records the original paths and Git blob hashes; every file was checked against its upstream hash and byte count before installation.

The skill-installer helper could not run because a Python runtime was unavailable. Files were retrieved through the connected GitHub tool and installed from verified local copies instead. These project-local skills are available to Claude when the project is opened in a new session.
